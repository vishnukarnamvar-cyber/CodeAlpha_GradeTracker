# 🎓 Student Grade Tracker

A web-based Student Grade Tracker built using Java, HTML, CSS, and JavaScript.

## 🚀 Features

- Add new students
- Enter student marks
- Automatic grade calculation
- Calculate average marks
- Find highest score
- Find lowest score
- Display total students
- Student performance indicator
- Delete individual students
- Clear all students
- Attractive web-based dashboard

## 🛠️ Technologies Used

### Backend
- Java
- Java HTTP Server
- Object-Oriented Programming
- REST-style API

### Frontend
- HTML5
- CSS3
- JavaScript
- Fetch API
